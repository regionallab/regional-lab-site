# Regional Lab アプリ（PWA）

Regional Lab 株式会社の Web サイトと同じ内容を、スマートフォンのアプリとして使えるようにしたものです。
ホーム画面に追加すると、ブラウザの枠のない「アプリ」として起動し、オフラインでも閲覧できます。

公開 URL（サイトと同じサーバに置いた場合）: `https://www.regional-lab.info/app/`

## 画面構成

下部の5つのタブで移動します。

| タブ | 内容 |
| --- | --- |
| ホーム | 理念・使命・展望、開催予定、四つの柱、最新のお知らせ、電話／メール／地図 |
| 事業 | 四つの事業 → 事業詳細（組織図のサービスをすべて展開） |
| イベント | 開催予定（お知らせの EVENT）／これまでの歩み（年表） |
| お知らせ | カテゴリ絞り込み・未読バッジ・記事詳細 |
| その他 | 私たちについて／会社概要／パートナー／お問い合わせ／検索／保存した項目／アプリについて |

アプリならではの機能:

- **保存**（しおりアイコン）— お知らせ・イベント・事業を保存し、「保存した項目」でまとめて見る
- **未読バッジ** — 未読のお知らせ件数をタブに表示。開くと既読になる
- **検索** — 事業・サービス・お知らせ・イベント・パートナー・メンバーを横断検索
- **共有** — 端末の共有シート（Web Share API）。非対応の環境ではリンクをコピー
- **オフライン閲覧** — Service Worker が本体と閲覧済みの画像をキャッシュ
- **ホーム画面に追加** — インストール可能なタイミングで案内を表示
- **日本語 / English** — サイトと同じ辞書（`../i18n.jsx`）。設定は両方で共有されます

## ファイル

```
app/
  index.html              アプリの外枠（フォント・Service Worker 登録・スプラッシュ）
  manifest.webmanifest    アプリ名・アイコン・起動 URL・ショートカット
  sw.js                   オフライン用 Service Worker
  app-core.jsx            配色・書体・保存領域（localStorage）・共通UI・ルーター
  app-screens.jsx         ホーム／事業／イベント／お知らせ
  app-more.jsx            その他タブ配下（私たちについて〜アプリについて）
  app-root.jsx            ルーティングとアプリバー・タブバー・インストール導線
  icon-192.png / icon-512.png / icon-maskable-512.png
```

コンテンツは持たず、サイトと同じ `../site-data.jsx`（日本語）と `../site-data-en.jsx`（英語）を読みます。
**文章や画像を直すときは、サイト側のこの2つのファイルを編集してください。サイトとアプリの両方に反映されます。**

ルーティングは URL のハッシュです（例: `#/business/re-lab`、`#/news/02`、`#/more/contact`）。
サーバ側の設定は不要で、静的ファイルを置くだけで動きます。

## ローカルで動かす

リポジトリのルートで静的サーバを立て、`/app/` を開きます（`file://` では Service Worker が動きません）。

```
npx http-server . -p 8080 -c-1
# → http://localhost:8080/app/
```

## 更新するとき

- **文章・画像を変えた** → `../site-data.jsx` / `../site-data-en.jsx` を編集
- **アプリの画面を変えた** → `app-*.jsx` を編集し、`sw.js` の `CACHE_VERSION` を上げる
  （上げないと、既にアプリを開いたことのある端末に古いキャッシュが残ります）
- **アイコンを差し替えた** → `manifest.webmanifest` と `index.html` の参照も確認

## 補足

- お問い合わせは、サイトと同じ Formspree（`formEndpoint`）へ送信します。未設定のときはメールソフトが起動します。
- 保存した項目・既読の状態は、その端末のブラウザ内にのみ保存されます（サーバには送りません）。
- React と Babel はサイトと同じ CDN・同じ integrity を使うため、ブラウザのキャッシュを共有できます。
